# ADR-0010: 공유 조건은 외부 정책 엔진 없이 도메인 코드 한 곳에 둔다

- 상태: accepted
- 날짜: 2026-11-04
- 관련: domain.md 4장, 13번, OSS-CANDIDATES

## 맥락
정책 엔진(OPA·OpenFGA·Casbin) 도입 제안이 있었다.

## 결정
공유 가능 조건과 상태 전이는 domain/sharing_rules에만 구현하고 속성 기반 테스트로 우회 경로가 없음을 검증한다. 정책 엔진은 쓰지 않는다.

## 결과
규칙이 한 곳에만 있어 검증·감사가 쉽다. 게이트웨이 단의 거친 인가가 필요해지면 그때 재검토한다.
