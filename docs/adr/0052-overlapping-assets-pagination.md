# ADR-0052: 이벤트 구간에 겹치는 자산의 페이지 조회

- 상태: accepted
- 날짜: 2026-11-12 (KST)
- 관련 요구사항: 07번 7.6, 09번 5.2

## 맥락

겹치는 자산 목록은 500건에서 잘렸다. 회차에 구간 클립이나 추출 프레임이 많으면 뒤쪽 자산을 포털과 API에서 볼 수 없었다.

## 결정

페이지 기본값과 최대값은 500건이다. 기존 촬영 시작 순서를 유지하며 시각이 같은 자산은 ID 순으로 정렬한다. 다음 커서는 마지막 자산의 원래 촬영 시작 시각과 ID를 담는다. 같은 이벤트와 필터로 커서를 사용한다.

촬영시각 미상 개수는 전체 필터 범위에서 계산한다. 각 페이지에서 같은 기관 범위를 확인한다. 포털은 더 보기 버튼으로 다음 페이지를 요청한다.

## 결과

500건 이후의 자산도 한 페이지씩 확인할 수 있다. 조회에는 기존 자산·이벤트 레코드를 사용하므로 마이그레이션이 없다.
