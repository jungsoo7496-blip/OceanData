# ADR-0000: ADR 양식

- 상태: 양식
- 날짜: 2026-11-04
- 관련: —

## 맥락
결정을 남기는 양식이다. 새 결정은 다음 번호로 파일을 만든다. 상태는 proposed / accepted / rejected / superseded 중 하나.

## 결정
아래 절을 채운다: 맥락(왜 결정이 필요한가), 결정(무엇을 택했나, 버린 대안과 이유), 결과(좋아지는 점·감수할 점·되돌리는 방법). PoC 결과라면 시험한 버전·커밋, 라이선스 파일 확인 결과, 합격 기준과 측정값을 적는다.

## 결과
Kiro는 설계 중 새 결정을 하면 이 양식으로 ADR을 만들고 tech.md 결정 대기 표를 갱신한다.
