# ADR-0043: 기기 자격 폐기 때 미사용 등록 코드 만료

- 상태: accepted (기본값, 운영 정책 확인 대기)
- 날짜: 2026-11-06
- 관련: 02번 요구사항 5.3, 5.4, 7.1

## 맥락

기기 자격을 폐기하면 수집기는 재등록 대기가 된다. 이전에 발급한 코드가 아직 유효하면 그 코드로 새 자격을 받을 수 있어 폐기를 우회할 수 있다. 폐기가 확인한 자격과 코드만 갱신하면 동시 등록도 놓칠 수 있다.

## 결정

폐기 때 사용하지 않은 유효 코드의 `expires_at`을 폐기 시각으로 설정한다. 폐기 성공 감사의 `enrollment_codes_invalidated`에 만료한 코드 수를 기록한다. 폐기된 코드로 등록하면 기존 만료 응답인 410 GONE과 `reason: EXPIRED`를 돌려준다.

API와 CLI의 발급, API의 등록과 폐기는 수집기 행을 먼저 `FOR NO KEY UPDATE`로 잠근다. 등록은 잠금 획득 뒤 코드를 다시 읽는다. 각 API의 성공 감사는 변경과 같은 트랜잭션에 기록한다.

코드를 그대로 두면 현장에 전달한 코드로 바로 재등록할 수 있지만 자격 폐기 뒤에도 접근을 되살릴 수 있다. 코드 삭제 방식은 기존 만료 응답과 기록을 잃으므로 만료 시각 갱신을 택했다.

## 결과

폐기 뒤 재등록하려면 관리자가 새 코드를 발급해야 한다. 자동 발급은 운영 정책 확인이 필요하다. 기존 코드와 자격 테이블을 사용하므로 새 마이그레이션이 없다. 정책을 되돌려야 한다면 향후 폐기 동작만 변경하고 이미 만료된 코드는 다시 활성화하지 않는다.
