# ADR-0009: MQTT는 센터가 아니라 현장 에이전트에서 받는다

- 상태: accepted
- 날짜: 2026-11-04
- 관련: 07·06번, tech.md

## 맥락
센서 기업 일부는 MQTT를 쓴다. 센터에 MQTT 브로커를 열면 외부 노출 포트가 늘고 인증 체계가 둘이 된다.

## 결정
센터는 HTTPS만 연다. MQTT는 에이전트의 Sensor_Plugin이 현장 브로커를 구독해 POST /v1/observations 배치로 보낸다. 다양한 산업 프로토콜이 필요하면 Telegraf를 현장 수집기로 PoC한다.

## 결과
엣지 push 원칙(바깥으로만 연결)과 같고, 오프라인 버퍼·재전송을 에이전트 것으로 재사용한다. 실제 토픽·페이로드는 연계 카드를 받은 뒤 정한다.
