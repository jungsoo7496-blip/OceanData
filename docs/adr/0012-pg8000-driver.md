# ADR-0012: PostgreSQL 드라이버로 pg8000 사용

- 상태: 채택
- 날짜: 2026-11-04
- 관련: tech.md 3장 라이선스 허용 목록, 01번 요구사항 9.3

## 맥락
SQLAlchemy의 일반적인 PostgreSQL 드라이버인 psycopg(3)·psycopg2는 LGPL-3.0/LGPL이라 코드에 링크되는 라이브러리 허용 목록 밖이다.

## 결정
순수 Python 드라이버 **pg8000 (BSD-3-Clause)** 을 쓴다. 접속 문자열은 `postgresql+pg8000://`.

## 결과
- 라이선스 허용 목록 안에서 동기 SQLAlchemy를 쓸 수 있다.
- C 확장 드라이버보다 느릴 수 있다. 05·17번 부하 시험(T12)에서 병목이면 asyncpg(Apache-2.0)로 바꾸는 ADR을 쓴다.
- 앱 코드는 SQLAlchemy만 쓰므로 드라이버 교체는 설정·의존성 변경으로 끝난다.
