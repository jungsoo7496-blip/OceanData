# ADR-0001: 스토리지는 S3 API 하나로 개발한다

- 상태: accepted
- 날짜: 2026-11-04
- 관련: tech.md HW-1, 04·08번

## 맥락
운영 스토리지 제품이 정해지지 않았다. GPT v0.05는 로컬 파일 어댑터를 먼저 만들고 S3 어댑터를 함께 두는 안이었다.

## 결정
처음부터 S3 API 공통 기능만 쓴다. 개발은 SeaweedFS(S3 게이트웨이), 단위 테스트는 moto. 로컬 파일 어댑터는 만들지 않는다.

## 결과
사전 서명·멀티파트를 로컬에서 흉내 내는 코드(운영에서 안 쓰는 코드)가 없다. 하드웨어가 오면 엔드포인트·자격증명 설정만 바꾸고, 제품별 호환 차이는 04·08번 통합 시험을 운영 스토리지로 다시 돌려 확인한다.
