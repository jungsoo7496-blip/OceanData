# ADR-0007: design.md·tasks.md는 Kiro가 만든다

- 상태: accepted
- 날짜: 2026-11-04
- 관련: structure.md 5장, README

## 맥락
GPT v0.05는 17개 스펙의 설계·작업 파일을 미리 채웠지만, 작업 112개 중 110개가 번호 순서로만 요구사항에 연결되어 있었고 설계의 공통 절은 모든 스펙에서 같았다.

## 결정
이 패키지는 requirements.md만 제공한다. 설계·작업은 Kiro가 요구사항을 읽고 만들며, 작업에는 실제로 구현하는 요구사항 번호를 단다.

## 결과
Kiro의 설계 검토 단계를 건너뛰지 않는다. 사람은 생성된 설계·작업을 검토해 승인한다.
