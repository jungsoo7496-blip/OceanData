# ADR-0026: 기관 하위 이벤트 코드 등록

- 상태: accepted
- 날짜: 2026-11-05
- 관련: 03번 요구사항 8.3, 작업 12

## 맥락

코드표 조회와 이벤트 등록은 이미 기관 하위코드를 지원한다. 기관 관리자가 등록할 수 있는 API가 필요했다.

## 결정

- `POST /v1/codes/event-categories/subcodes`로 기존 상위분류 아래에 등록한다. 하위 경로를 사용해 기존 `GET /v1/codes/{table}` 경로와 함께 제공한다.
- 사람 `ORG_ADMIN`의 인증 기관과 주체를 기록한다. 상위분류는 기존 공통 코드표를 읽어 확인한다. 응답과 조회는 기관 코드 항목에 `organization_specific: true`를 붙인다.
- 0002의 `org_event_codes`와 복합 기본키를 사용한다. 기관 내 중복은 409이고 다른 기관은 같은 코드를 독립적으로 등록할 수 있다. 입력 문법 오류는 400, 등록되지 않은 상위분류는 422다.
- 같은 기관·주체·경로·멱등성 키의 동시 요청을 트랜잭션 잠금으로 직렬화한다. 같은 본문은 첫 201 응답을 돌려주고 다른 본문은 409를 반환한다. 등록, 멱등성 응답 및 성공 감사 `ORG_EVENT_CODE_CREATED`를 같은 트랜잭션으로 확정한다. 권한 거부 감사는 기존의 별도 커밋 경로를 사용한다.

## 결과

공통 코드표 버전, 기존 이벤트 계약, DB 구조를 유지한다. 신규 마이그레이션과 down은 해당 없다.
기능을 되돌리려면 신규 등록 라우트와 권한을 제거한다. 기존에 등록된 기관 코드는 이미 발행한 이벤트가 참조하므로 조회와 검증에서 유지한다.
