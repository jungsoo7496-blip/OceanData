# ADR-0020: 비식별·태깅·장면 검색의 기준선 구현 (모델 확정 전)

- 상태: accepted (모델 선정 후 superseded 예정)
- 날짜: 2026-11-04
- 관련: 14번 요구사항 2, 6, 7, 8, AGENTS.md 5번(외부 사실을 지어내지 않음), OSS-CANDIDATES.md(모델은 라이선스 검토 후)

## 맥락
14번은 얼굴·번호판·선박 문자 탐지, 객체 태깅, 문장 장면 검색을 요구한다. 실제 모델은 아직 정하지 않았고(라이선스·가중치 학습
데이터 조건 검토 필요), 모델 이름이나 성능을 지어내면 안 된다. 그래도 흐름(대상 제한 → 가림 → 처리 기록 → 검수 → 상태 반영 →
품질 집계, 태깅 → 이벤트, 임베딩 → 검색)은 지금 완성하고 시험해야 한다. GPU 없이도 동작해야 한다(T16-a).

## 결정
1. **탐지기는 포트 뒤**: `DetectorPort` — `SyntheticRegionDetector`(합성 시험 영상의 `ext.synthetic_regions`를 그대로 돌려주는
   모의 구현, 기본값)와 `OnnxRegionDetector`(Model_Registry 라이선스·sha256 검사 후 로드, 모델별 전처리·후처리는 모델 확정 후)를
   둔다. 설정 `DEID_DETECTOR=synthetic | onnx:<이름>@<버전>`. 모의 탐지기는 실제 영상에서 아무것도 찾지 않는다 — 운영 전 교체 필수.
2. **가림은 ffmpeg 필터**(블러 `boxblur`·모자이크 축소/확대·채움 `drawbox`), 구간별 `enable=between(t,…)`. 추적 옵션은 같은 클래스·
   가까운 위치의 짧은 끊김을 이어 붙이는 보간. CPU로 동작하고 `make bench`에 처리량을 남긴다.
3. **태깅 기준선**: 주야는 표본 프레임 평균 밝기(임계값 설정), 객체는 모의 입력(`ext.synthetic_objects`). 태그 → 이벤트는 정책 표
   `tag_event_rules`(source=MODEL, human_verified=false).
4. **장면 임베딩 기준선**: 태그 어휘 16차원 벡터(`tag-vocab-baseline@1`), 문장은 한국어 낱말 → 어휘 사전으로 같은 공간에 넣는다.
   pgvector `vector(16)` 표에 모델 이름과 함께 저장하므로, 실제 임베딩 모델(다른 차원)을 붙일 때 모델별 표·인덱스를 더한다.
5. **표기**: 처리 결과는 "처리 이력"으로만 보여 주고 적정성 보증·면책 문구를 쓰지 않는다 (요구사항 5.4).

버린 대안: 공개 모델 하나를 골라 바로 넣기 — 라이선스(AGPL·비상업 조건 등)와 학습 데이터 조건 검토 전이라 쓰지 않는다.

## 결과
- 흐름·상태·권한·집계를 지금 시험할 수 있고(T09), 모델을 붙이면 포트 구현과 Model_Registry 등록만 바꾸면 된다.
- 감수: 기준선은 실제 영상에서 쓸모가 없다(모의 탐지, 어휘 검색). 운영 도입 전 모델 선정·실측(GPU 도입 후)이 필요하다.
