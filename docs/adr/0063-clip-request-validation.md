# ADR-0063: 구간 클립 요청의 입력·품질·멱등 키 보완

- 상태: accepted
- 날짜: 2026-11-12
- 관련: 09번 요구사항 7.2(구간 클립), ADR-0033(클립 쿼터·대기 한도), ADR-0053(같은 멱등 키 대기), security.md 입력 검증, 지시서 12번 클립·업로드 검토 C12

## 맥락

검토(C12)에서 `POST /v1/assets/{asset_id}/clips`의 빈틈 네 가지가 나왔다.
1. **사유**는 감사 로그(`CLIP_EXPORT_REQUESTED`)에 남는데, C0 제어 문자와 DEL만 막아 C1 제어 문자(U+0085 NEL 등)·줄/문단 구분(U+2028·U+2029)·방향 제어(U+202E 등)가 들어갔다.
   로그·화면에서 줄이 바뀌거나 글 순서가 뒤집혀 보여 감사 기록을 읽는 사람을 속일 수 있다.
2. **구간**은 계약상 JSON 숫자인데 서버가 문자열 `"0"`·`true`를 숫자로 바꿔 받아 0·1초 구간 작업을 만들었다.
3. **품질**: 파생 자산은 만들 때 모두 `PASSED`로 시작해, 촬영 시각을 모르는 원 영상(품질 `WARNING`, `capture_time_unknown`)의 클립도 시각이 미상인데 `PASSED`였다.
4. **멱등 키**: 쓰기 요청은 `Idempotency-Key`를 받는다는 규칙(api-conventions.md)과 달리 이 작업은 받지 않았다. 같은 구간이 대기·실행 중이면 같은 작업을 돌려주지만, 작업이 끝난 뒤 재시도하면 새 작업이 생겼다.

## 결정

1. 사유 패턴에서 C0·DEL에 더해 **C1(U+0080~U+009F), U+200E·U+200F, U+2028·U+2029, U+202A~U+202E, U+2066~U+2069**를 막는다. 계약 `ClipRequest.reason.pattern`과 서버 모델이 같은 식이다.
2. 구간은 **엄격한 JSON 숫자**(`strict=True`)로 받는다. 정수(`1`)는 숫자라 그대로 받는다.
3. 클립 결과 자산에는 **등록 때와 같은 품질 규칙(`apply_rules`)**을 적용한다. 원 영상 촬영 시각이 미상이면 클립도 미상이라 `capture_time_unknown`(규칙이 정한 WARNING·FAILED)이 붙는다.
   프록시·썸네일 같은 처리 산출물은 이번에 바꾸지 않는다 — 새 촬영 구간을 가진 자산은 클립뿐이다.
4. **`Idempotency-Key`를 받는다**(다른 쓰기와 같은 `run_idempotent`). 키 범위는 사용자 × `POST /v1/assets/{asset_id}/clips` × 키, 본문은 요청 본문이다.
   같은 키·같은 본문은 작업이 끝난 뒤에도 처음 응답(`Idempotent-Replayed: true`, 새 작업·감사 없음), 다른 본문은 409 `IDEMPOTENCY_CONFLICT`. 키가 없으면 지금처럼 진행 중인 같은 구간 작업을 돌려준다.

버린 대안: 사유의 모든 서식 문자(Cf 전체)를 막기 — 한글 입력에 쓰일 수 있는 ZWJ·ZWNJ 같은 글자까지 막혀 정상 입력이 400이 된다. 이번에는 줄 구분과 방향 제어만 막는다.

## 결과

좋아지는 점: 감사 로그의 사유가 보이는 그대로다. 잘못된 형식의 구간이 엉뚱한 작업이 되지 않는다. 시각 미상 클립이 품질 경고를 받는다. 재시도해도 작업·감사가 한 번이다.

감수할 점: 전에는 받던 요청(문자열 숫자·해당 문자 사유)이 400이 된다 — 계약이 원래 허용하지 않던 입력이다. 다른 작업의 사유 필드(삭제 등)는 아직 같은 검사를 하지 않는다.

되돌리는 방법: `ClipRequest`의 `strict`·`CLIP_REASON_PATTERN`, `create_asset_clip`의 `run_idempotent`, `clips.py`의 `apply_rules` 줄을 되돌리고 계약의 해당 줄을 되돌린 뒤 웹 타입을 다시 만든다. 마이그레이션 없음.

시험: `tests/integration/test_clip_request_validation.py` 13개 — 사유의 보이지 않는 문자 7가지, 문자열·참거짓 구간 4가지, 시각 미상 원 영상의 클립 품질, 멱등 키(끝난 뒤 재응답·감사 한 번·다른 본문 409). 수정 전 코드에서 13개 모두 실패하는 것을 확인했다.
