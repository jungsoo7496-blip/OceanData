# ADR-0051: 원천 장비를 매핑하기 전 수집기의 기본 정책

- 상태: accepted
- 날짜: 2026-11-12 (KST)

## 맥락

수집기를 등록하고 기기 자격증명을 발급할 때 원천 장비가 아직 매핑되지 않을 수 있다. 이때 서버가 생성하는 기본 정책에는 원천 장비와 감시 규칙이 없다. 기존 스키마의 원천 장비 최소 항목 수와 ADR-0040의 배포 전 검사가 결합돼 정책 조회는 422를 반환했다. 새 에이전트는 유효한 정책을 받을 때까지 하트비트를 시작할 수 없었다.

## 결정

서버 생성 기본 정책 `pv-0`에 `sources: []`와 `watch_rules: []`를 허용한다. 수집기는 기본 주기로 하트비트를 보내며 감시 규칙을 적용할 원천이 생길 때까지 대기한다. 프로젝트가 연결된 원천 장비를 매핑하면 다음 기본 정책 조회에 해당 장비가 나타난다.

저장할 정책과 저장본에서 배포할 정책은 계약의 `storedPolicy` 검사를 적용하며 원천 장비를 한 대 이상 포함해야 한다. 기술 상한을 비롯한 나머지 배포 검사는 ADR-0040을 따른다.

## 결과

원천 장비 매핑 전에도 수집기의 연결 상태를 관측할 수 있다. 정상 초기화에 필요한 데이터는 기존 장비 레코드와 기본값을 사용한다. 마이그레이션은 없다.
