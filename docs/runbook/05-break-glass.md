# 05 긴급 열람

> **확인 필요:** 02번 요구사항 8(긴급 열람 승인·기한·사후 검토)은 아직 구현되지 않았다. 아래는 구현 시 따를 초안이다.

**판단 기준:** 안전사고·법적 요청 등으로 운영자가 기관 원본을 봐야 하는데 정상 권한이 없을 때.

**사람이 할 것 (초안)**
1. 요청 사유·범위·기한을 문서로 받는다 (기관 ORG_ADMIN 또는 법무 승인).
2. 긴급 열람 부여(구현 후 API) → 열람 → 기한 만료 또는 즉시 회수.
3. 사후: 감사 로그에서 열람 내역을 뽑아 기관에 통지.

**완료 확인:** 부여·열람·회수가 모두 감사 로그에 있고 기관 통지 기록이 있다.
