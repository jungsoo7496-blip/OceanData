# 04 자격증명 폐기 (장비·API 키)

**판단 기준:** 현장 PC 분실·교체, 담당자 퇴사, 비정상 업로드, 토큰 유출 의심(09).

**자동 대응:** 폐기하면 다음 요청부터 401(재등록 필요). 기기 토큰은 매 요청 DB에서 폐기 여부를 본다 (ADR-0013).
에이전트는 401을 받으면 업로드를 멈추고 상태에 "재등록 필요"를 표시한다.

**사람이 할 것**
1. ORG_ADMIN(다중 인증): 장비 화면 → 수집기 → "자격증명 폐기" 또는 `POST /v1/devices/{id}/credentials/revoke`.
2. API 키: `POST /v1/api-keys/{id}/revoke`.
3. 다시 쓸 장비면 새 등록 코드 발급 → 현장에서 `marine-agent enroll` (장비 화면 설치 안내).
4. 감사 로그에서 폐기 전후 그 자격증명의 요청 확인: `GET /v1/audit-logs`.

**완료 확인:** 폐기된 토큰으로 `GET /v1/me` 401, 수집 모니터링에서 해당 수집기 하트비트 무응답 경보가 예상대로 열림(재등록 전).
