# 08 디스크·쿼터 용량 임계

**판단 기준:** 기관 쿼터 80·90·100% 알림(08번), STORAGE_FORECAST 경보(11번), 현장 LOCAL_DISK_LOW 경보, 하드웨어 신호 DISK·SMART 경고.

**자동 대응:** 쿼터를 넘는 업로드 생성은 409(QUOTA_EXCEEDED). 에이전트는 원본을 지우지 않고 대기열에 둔다.

**사람이 할 것**
1. 운영 콘솔 → 기관 사용량(항목별: 등록·격리·예약·백업).
2. 보존 만료 미리 보기 `POST /v1/retention/dry-run` → 검토 후 `python -m app.cli retention --execute`.
3. 격리 자산 정리(ORG_ADMIN 폐기 확정), 기관과 쿼터 조정 협의.
4. 현장 디스크: 기관 담당자에게 전송 완료 파일 정리 안내 (에이전트는 원본을 지우지 않는다).

**완료 확인:** 사용률이 임계 아래, 관련 경보 해제, 보존 실행이면 삭제 증명(dlc_) 발급.
