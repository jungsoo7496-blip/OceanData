- [x] 28. 보고서 내보내기 보강: HWPX 양식 검사, PDF 가져오기 금지·동시 렌더 상한 — 요구사항 4.5, 4.6 · 세 가지 문제를 고쳤다(검토 2026-11-12 V7·V8): UTF-8이 아니거나 읽을 수 없는 HWPX 양식이 PUT 200·내보내기 500이던 것, zip 항목 이름 검사가 POSIX 형태만 막던 것, PDF 렌더러가 http·file 주소를 가져오고 느린 렌더에 상한이 없던 것. 검사와 렌더가 같은 함수로 모든 항목을 256KiB 조각으로 읽는다(헤더에 적힌 크기까지, XML은 점진 디코더로 UTF-8만, 검사는 글을 만들지 않음). 이름은 역슬래시·`:`·제어 문자(C0·C1)·보이지 않는 서식 문자를 거부한다. PUT은 400, 검사 전에 저장된 양식으로 내보내면 409. PDF는 언제나 거부하는 URL fetcher를 쓰고, `REPORT_PDF_MAX_CONCURRENT`(기본 2)가 차면 429 + Retry-After. 계약 설명을 먼저 고쳤다. 시험 `tests/unit/test_report_export_hardening.py`·`tests/integration/test_report_export_hardening.py`.
