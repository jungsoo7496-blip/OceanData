# 제품 개요 — 해양 실증데이터 플랫폼

## 무엇을 만드는가
해양 규제자유특구 실증기업(선박 카메라, 해수욕장 CCTV, 센서, AI 기업)이 실증 중 생산하는 데이터를
**자동으로 수집**하고, **표준 메타데이터로 정리**하며, 기업이 **실증업무(일지·증빙·보고서·영상 검색)** 에 쓰게 하고,
기업이 승인한 **부산물(환경) 데이터만 비식별·검수 후** 다른 기업의 AI 개발에 **승인형으로 공급**하는 소프트웨어.

한 줄 정의: **실증업무 워크스페이스 + 자동수집 + 표준화 + 승인형 공동활용**

## 사용자 (역할 코드는 domain.md)
- 제공기업 관리자 / 담당자: 장비 연결, 실증회차 관리, 보고서 작성, 공유 승인
- 관리기관 열람자: 실증 진행·수집 정상성·제출 지표 확인 (원본 열람 불가)
- 플랫폼 운영자: 기관·장비·정책 관리, 처리 현황, 공동활용 최종 승인
- 검수자: 비식별·라벨 품질 검수
- 이용기업: 승인된 데이터셋 이용

## 절대 원칙 (모든 기능이 지켜야 함)
1. 업로드는 업무의 부산물이다. 기업에게 별도 입력을 요구하지 않는다 (기업이 직접 입력하는 필수 메타데이터 0개).
2. **업로드 ≠ 공유.** 모든 데이터의 기본 공유 등급은 L0(기업 단독).
3. 공유 가능 조건은 사람의 판단이 아니라 **시스템 규칙으로 강제**한다 (domain.md "공유 가능 조건").
4. 핵심 데이터(data_role=CORE)는 L1을 넘을 수 없다.
5. 외부 이용기업에는 원본을 제공하지 않는다.
6. 촬영시각 등 근거가 없는 값은 지어내지 않는다. 미상은 미상으로 기록한다.
7. 모든 접근·변경·반출은 감사 로그에 남는다.
8. 하드웨어 미확정 상태에서 개발한다. 스토리지 제품·GPU·배포 형태에 의존하지 않는다 (tech.md 하드웨어 독립 규칙).

## 범위
- 포함: 수집(에이전트·웹·API), 센서 관측값·실증 이벤트 수집(REST·CSV, MQTT는 에이전트 플러그인), 저장·보존, 처리 파이프라인(메타 추출·프록시·선별 비식별·태깅), 검색·뷰어, 실증 워크스페이스·보고서, 관리기관 보드, 운영 콘솔, 수집 모니터링·정기 점검, 공유·데이터셋·승인형 배포, 공공 Open API 수집
- 조건부: 엣지 수집기(앵커 기업 장비 확인 후), NGSI-LD 어댑터·광역 데이터 허브 연계(도입 게이트 통과 시)
- 제외: 결제·정산·크레딧, 이용기업 대상 대규모 GPU 학습 환경, 웹 크롤링, 실시간 관제

## 성공 기준 (저장량이 아님)
- 사람 개입 없이 자동 수집되는 기업 비율
- 보고서·증빙 준비 시간 절감
- 승인된 데이터셋의 실제 이용 건수
- 미승인 노출 0건

## 기준 문서
사업 전체 맥락·근거·수치 산정은 `docs/baseline-v0.04.md` (채팅에서 `#baseline-reference` 로 불러옴).
스펙과 기준 문서가 충돌하면 steering 파일(product·tech·structure·domain)이 우선한다.
